# 美港股支持增强设计文档

## 概述

本文档描述了增强美港股数据支持的详细设计方案。

**解决问题：**
- 港股指数数据缺失（恒生指数 HSI、恒科指数 HSTECH）
- 美股指数数据缺失（纳斯达克指数 IXIC）
- 部分美股代码搜索不到（如 SOXL、OKLO、TSLA等）

**目标：** 提供完整的美港股指数数据和更好的搜索体验

**数据源：** 继续使用东方财富API（免费、稳定）

## 当前问题分析

### 1. 指数数据不完整

当前 `INDEX_CONFIG` 只包含：
```python
INDEX_CONFIG = {
    "sh": {"secid": "1.000001", "name": "上证指数", "currency": "¥"},
    "sz": {"secid": "0.399001", "name": "深证成指", "currency": "¥"},
}
```

**缺失的指数：**
- 港股： 恒生指数(HSI)、恒生科技指数(HSTECH)
- 美股: 纳斯达克指数(IXIC)、道琼斯指数(DJI)、标普500(SPX)

### 2. 美股搜索不全

**问题表现：**
- 某些美股代码无法搜索到（如 SOXL、OKLO、TSLA等）
- 搜索功能对美股支持有限

**可能原因：**
- 东方财富数据库中美股数据不全
- secid映射规则不准确

## 设计方案

### 方案概述

继续使用东方财富API作为唯一数据源，- **优点：** 免费、稳定、已在项目中使用
- **缺点：** 部分美股可能搜不到

### 前端展示方案

**方案C：分开展示（推荐）**

三个独立的区块：
1. A股指数区（上证、深证）
2. 港股指数区（恒生、恒科）

- 市场清晰
- 便于扩展
- 用户体验好

### 搜索策略优化

1. **先尝试精确匹配**： 直接用代码搜索
2. **如果失败，尝试模糊搜索**： 搜索名称关键词
3. **支持ETF搜索**： 扩展到ETF产品

## 数据流程

```
用户输入代码/指数名称
    ↓
判断市场类型（a/hk/us/index）
    ↓
构造secid
    ↓
调用API获取数据
    ↓
返回结果（包含名称、价格、涨跌幅等）
```

## 错误处理

### 1. API调用失败
- 记录错误日志
- 返回None或空结果
- 前端显示"数据获取失败"

### 2. 无效代码
- 返回空搜索结果
- 前端显示为不可选择（灰色）

### 3. 网络超时
- 5秒超时限制
- 可选：重试机制

## 测试计划

   - 测试所有新增指数（HSI、HSTECH、IXIC等）

3. **性能测试**

   - 测试搜索响应时间
