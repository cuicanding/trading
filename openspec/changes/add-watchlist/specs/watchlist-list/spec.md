# 自选股列表

## 用户故事

作为一个登录用户，我想要管理我关注的股票列表
以便快速查看价格变动。

## 功能说明

### 添加自选股

**输入**: 股票代码（如 600519.SH）
**流程**:
1. 用户输入股票代码
2. 系统验证代码格式
3. 调用Tushare获取股票名称
4. 检查是否已在自选股中
5. 保存到数据库

**输出**: 成功/失败提示

### 删除自选股

**输入**: 自选股项ID
**流程**:
1. 用户点击删除按钮
2. 显示确认对话框
3. 确认后从数据库删除
4. 刷新列表

**输出**: 删除成功提示

### 查看自选股列表

**流程**:
1. 从数据库获取用户自选股
2. 调用Tushare获取实时价格
3. 合并数据展示

**展示字段**:
- 股票代码
- 股票名称
- 现价
- 涨跌幅（带颜色）
- 成交量
- 分组

### 分组筛选

**流程**:
1. 点击分组标签
2. 按分组过滤列表

### 搜索过滤

**输入**: 搜索关键词
**流程**:
1. 实时过滤匹配股票

## 技术实现

### State

```python
class WatchlistState(AuthState):
    watchlist_items: List[dict] = []
    groups: List[dict] = []
    selected_group: str = ""
    search_query: str = ""
    is_loading: bool = False
    add_dialog_open: bool = False
    delete_confirm_id: str = ""
    new_stock_code: str = ""
```

### Events

- `load_watchlist()` - 加载自选股列表
- `add_to_watchlist(stock_code)` - 添加自选股
- `remove_from_watchlist(item_id)` - 删除自选股
- `filter_by_group(group_id)` - 按分组过滤
- `search_stocks(query)` - 搜索股票
